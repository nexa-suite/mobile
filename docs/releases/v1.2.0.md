# Nexa Mobile v1.2.0 candidate

Application source was merged to `main` through [PR #46](https://github.com/nexa-suite/mobile/pull/46) on 2026-10-11 (Lima), then repository cleanup was merged through [PR #43](https://github.com/nexa-suite/mobile/pull/43). The latest application-source tree is `fba5046c0641574b166eb9acdd15b548155b496b`, shared by PR #43 head `42d4d367d27d7a4252fa9ed22fc610148ce516a3` and merge commit `bb70b8a28fae0108b65061d0b5934e836b5049b8`. PRs #47 and #48 update documentation only. This is a source-only release candidate for local suite testing. The signed `v1.2.0` tag and corresponding GitHub Release have not been published.

Operations Android is version `1.2.0` (`versionCode 11`). Buyer Flutter remains independently versioned at `1.1.0+2`; its iOS target follows the Flutter version.

## Included changes

- Add scoped Operations and Buyer notification inbox, read state and preferences for accepted `IN_APP` and `EMAIL` channels. Push delivery is outside this release.
- Add Buyer wallet PaymentSheet checkout with scoped retry identity. Payment status remains server-confirmed; the app does not infer wallet credit.
- Publish workforce scope and commercial permission hints through BC-01 application APIs, translate Catalog scope at its adapter boundary, and reject dependencies between context domains.
- Allow a new Direct Order decision after recovered permission or unavailable terminal outcomes while retaining same-key replay for uncertain outcomes.
- Update Mobile release evidence and repository guidance for v1.2.0.

## Distribution and known limits

Planned distribution is source only. No official signed Operations APK, Buyer distribution build, or other binary artifact is attached. The Operations verification APK was unsigned; the Buyer artifact was a debug APK. iOS distribution was not verified.

The Direct Order screen, ViewModel, coordinator, route and local retry tests exist. Live Tenant API acceptance of MOB-US-009 outcomes (`201 CONFIRMED`, prepaid `202 PENDING`, and same-key retry after an uncertain result) remains unverified. Full delivery detail/event fixture coverage also remains follow-up work. Live API compatibility, Product/UX acceptance, System Acceptance, physical-device acceptance, and production deployment are not claimed.
