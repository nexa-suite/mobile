## Distribution boundary

The Operations R8 build is unsigned and is not a distribution APK. It has not
been verified with the official distribution certificate; no signed
distribution artifact was uploaded or published. No Buyer Android
distribution signer was found or reused. The validation origins used for
assembly do not establish live API compatibility. Product/UX Acceptance,
System Acceptance, live service compatibility, physical-device verification,
and production readiness remain open release gates. The v1.2.0-alpha.1
prerelease is a source checkpoint; this candidate remains unreleased and ready
for source review only.
