# Nexa Mobile v1.2.0 candidate — unreleased

This source candidate is prepared for review; no `v1.2.0` tag or GitHub release
exists. Operations Android is set to `1.2.0` (`versionCode 11`). The separate
Buyer Flutter app is set to `1.1.0+2`; its iOS target version follows the same
Flutter build name and number. These are independent application versions.

## Technical verification

The following checks passed on the candidate source with strict dependency
verification and JDK 17:

- `./gradlew --console=plain --quiet verifyAndroidArchitecture ktlintCheck lintDebug testDebugUnitTest :app:assembleDebug --dependency-verification strict`
- `./gradlew --console=plain --quiet :app:assembleRelease -PnexaReleaseApiBaseUrl=https://nexa-api-69bj.onrender.com/ --dependency-verification strict`
- `python3 scripts/verify-context-architecture.py` (`11` canonical context
  roots and layer boundaries).

The release assembly ran R8 and resource shrinking, and produced
`app/build/outputs/apk/release/app-release-unsigned.apk`. It is unsigned and is
not a distribution APK. The connected API 29/37 suite has not been run on these
candidate changes; previous connected-test results are not evidence for this
source revision.

Buyer Flutter `flutter analyze` passed with no issues. `flutter test
--reporter compact` passed 94 tests; four opt-in local-API integration tests
were skipped because the local API fixture was not available. Strict Android
debug assembly passed with JDK 17. The iOS no-codesign build did not start:
Xcode 27 could not load `IDESimulatorFoundation` because the installed
`CoreSimulator.framework` path is missing. These Buyer checks are separate
from the Operations Android checks; iOS distribution signing remains
unavailable.

## Distribution boundary

The Operations R8 build is not evidence of live API compatibility. The current
Render service does not establish compatibility with the Tenant capabilities
represented in this source candidate. The Operations artifact has not been
signed and verified with the official distribution certificate; no Buyer
Android distribution signer was found or reused. No signed distribution
artifact was uploaded or published. The separately documented alpha
prerelease is a source checkpoint. Product/UX Acceptance, System Acceptance,
live service compatibility and production readiness remain open release
gates; these do not prevent source review.
