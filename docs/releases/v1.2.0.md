# Nexa Mobile v1.2.0 candidate — unreleased

This is a local source candidate only. No tag or release was created.
Operations Android is set to `1.2.0` (`versionCode 11`). The separate Buyer
Flutter app is set to `1.1.0+2`; its iOS target version follows the same Flutter
build name and number. These are independent application versions.

## Technical verification

Operations Android gates passed on the current working tree with strict
dependency verification and JDK 17:

- `verifyAndroidArchitecture`, `ktlintCheck`, `lintDebug`,
  `testDebugUnitTest`, `:app:assembleDebug` and `:app:assembleRelease` passed.
  The release build ran R8 and resource shrinking against the Render validation
  origin `https://nexa-api-69bj.onrender.com/`.
- JVM XML reports record 561 tests across 121 result files, with zero failures,
  errors or skips.
- The ordinary connected suite passed 65 tests on each API 37 and API 29 AVD,
  with zero failures, errors or skips. It excluded the private-fixture-only
  `LiveCandidateIdentityIntegrationTest` and `RoleWireflowCaptureTest` cases.

Buyer Flutter `flutter analyze` passed with no issues. `flutter test
--reporter compact` passed 94 tests; four opt-in local-API integration tests
were skipped because the local API fixture was not available. Strict Android
debug assembly passed with JDK 17. The iOS no-codesign build did not start:
Xcode 27 could not load `IDESimulatorFoundation` because the installed
`CoreSimulator.framework` path is missing. iOS distribution signing remains
unavailable.

## Distribution boundary

The Operations R8 build is not evidence of live API compatibility. The current
Render service does not establish compatibility with the Tenant capabilities
represented in this source candidate. The v1.2.0 Operations artifact has not
yet been signed and verified with the official distribution certificate; no
Buyer Android distribution signer was found or reused. No signed distribution artifact was uploaded or published. The separately documented alpha prerelease is a source checkpoint. Product/UX Acceptance, System Acceptance, live service
compatibility and production readiness remain separate gates.
