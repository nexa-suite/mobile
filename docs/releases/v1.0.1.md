# Nexa Operations Mobile v1.0.1

Patch for controlled direct distribution, based on the integration of [PR #34](https://github.com/nexa-suite/mobile/pull/34). Android version `1.0.1`, version code `9`.

## Changes

- Preserve the manifest-discovered ML Kit registrar constructors during release shrinking, correcting the scanner crash when camera permission is granted.
- Show retry and manual identification when scanner initialization is unavailable.
- Add **Cerrar sesión** to the work entry screen, using the existing secure session cleanup.
- Display granted operational actions as cards and remove three informational shortcuts from the hub. Server permissions remain authoritative.

## Verification

Architecture, formatting, lint, strict dependency verification, debug and release assembly passed. The local JVM suite reported 467 tests with no failures. Seven focused Android navigation/scanner tests passed; the API 37 suite selected 58 tests with one optional assumption skip. GitHub verification of the integrated source passed static checks, API 37 and the API 29 promotion gate.

The team also confirmed that the camera works in its manual check. That confirmation is separate from the automated test results.

## APK

`nexa-operations-v1.0.1.apk` uses the same official distribution certificate as v1.0.0 and targets `https://nexa-api-69bj.onrender.com/`. Its checksum is provided in `SHA256SUMS`. Signing material is excluded from the repository.

This patch does not change API behavior or resolve the previously reported Warehouse-to-Dispatch data scenario. No Play Store publication is claimed.
