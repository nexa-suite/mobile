# Nexa Mobile v0.2.0 — proposed engineering preview

Status: proposed and unpublished. No tag, merge, GitHub Release or release
artifact has been created by this preview work.

## Scope

This milestone packages the native foundation for the AV1 Nexa Operations
preview:

- Kotlin + Jetpack Compose single-Activity Android application.
- Moderate `:core:*` and `:feature:access` modules.
- Typed Navigation 3 route keys and explicit launch states.
- Keystore-backed encrypted session material interface.
- Typed Problem Details/error mapping and localized `en-US`/`es-419` shell.
- Host, CI and pinned Docker verification commands.

The planned AV1 story boundary is `MOB-US-001`, `MOB-US-002`, `MOB-US-003`,
`MOB-US-011` and `MOB-US-012`. This foundation does not complete those
stories. Connected authentication is blocked by unresolved
`ClientSurface` semantics in API `v0.17.0`; warehouse identification is not
started on this branch.

## Evidence boundary

Verified in the feature worktree:

```text
./gradlew testDebugUnitTest lintDebug assembleDebug       PASS
```

The host build uses the project-selected JDK 21, AGP 9.0.1, Gradle 9.1.0 and
compile/target SDK 36. AGP 9.0.1 upstream minimum/default JDK is 17; JDK 21 is
not claimed as an AGP requirement. No emulator, physical-device, live API
authentication or SKU-resolution evidence is claimed. Docker and
human-owner/SCM gates remain required before publication.
