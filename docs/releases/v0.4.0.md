# v0.4.0 — Operations Android

This source version integrates approved Operations V1 workflows and the known
functional remediation following v0.3.0-alpha.1. The Android application remains
Kotlin/Compose with server-authoritative authorization and business outcomes.

## Changes

- Warehouse identification, receiving, stock consultation and cold-chain evidence.
- Dispatch planning, delivery execution and explicit exception coordination.
- Scoped session recovery, protected local credentials and bounded command replay.
- Android 17 local-network permission recovery for the local debug API.
- Readable Warehouse and zone selection, native flow captures and the Nexa launcher icon.
- Strict verification of dependency binaries, sources and documentation artifacts.

## Delivery limits

The local APK uses the emulator API origin and Android debug signing. It is a
local evaluation build, not production distribution. No production API endpoint,
distribution key or credentials are included in Git or release assets.
Physical-device camera/tracking checks, provider readiness, Product/UX Acceptance
and System Acceptance remain separate. Sales/Buyer chat excludes Driver chat;
automatic IoT and advanced routing remain outside approved V1 scope.
