# Nexa Operations Mobile v0.6.0

Fecha: 3 de octubre de 2026.

Esta versión prepara un candidato académico del cliente Android con `versionCode 7`. La compilación de depuración puede apuntar al origen HTTPS público de validación de Nexa mediante la propiedad de Gradle `nexaDebugApiBaseUrl`; el valor aprobado para esta revisión es `https://nexa-api-69bj.onrender.com/`.

La comprobación local estricta pasó arquitectura, formato, lint y las pruebas JVM. El APK de depuración se compiló, instaló y abrió en un emulador Android disponible, y se cerró sin dejar el proceso activo. La ejecución en un dispositivo físico, la autenticación con cuentas reales, los recorridos de aceptación y las capturas finales siguen siendo validaciones independientes.

La ejecución instrumental ordinaria realizó 54 pruebas en un emulador API 29. La prueba de identidad remota quedó fuera mediante su filtro opt-in documentado; la prueba de recorrido por rol llegó a su precondición de credenciales y registró una aserción de suposición porque no se proporcionó una cuenta de rol autorizada. Por ello, el candidato aún no acredita inicio de sesión remoto ni recorrido por rol.

El repositorio incorpora un flujo manual de GitHub Actions para construir el APK de depuración con ese origen HTTPS y conservarlo como artefacto académico temporal. El artefacto no está firmado para distribución, no contiene credenciales y no representa una publicación en Play Store ni una preparación de producción.

La readiness/liveness del servicio remoto respondió correctamente durante esta revisión. El indicador agregado de salud del servicio continúa reportando una dependencia de correo no configurada; por ello esta versión no declara disponibilidad integral de producción.
